# Duel Night 3D (buddylist fork)

Fork of Ali's https://duel3d.netlify.app with:
- **touch controls** (shows on phones/tablets, or add `?touch`): joystick + LP/MP/HP/LK/MK/HK, one-tap specials/supers, START/PAUSE
- two new fighters: **TIM** (Applied AI) and **ABE** (Scale to Zero), styled after their GitHub photos, which are also their portraits

Play: https://buddylist.github.io/duel3d/
